# Agent entrypoint

Read the root [`AGENTS.md`](AGENTS.md) and the nearest nested `AGENTS.md` for
every file you edit. Use `python tools/agent.py doctor`, bounded context through
`python tools/agent.py context ...`, and the public gate through
`python tools/agent.py check --base origin/main`.

There are no Gemini-specific recovery rules; `AGENTS.md` is the single source of
truth.
