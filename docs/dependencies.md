# Dependencies

## Required for public-safe agent work

- Git
- Python 3.10 or newer

The recovery index, context packs, metadata validation, source-quality review,
and unit tests use only the Python standard library.

Verify the workspace with:

```sh
python tools/agent.py doctor
```

## Required for local decompilation builds

- [Ninja](https://ninja-build.org/)
- A legally obtained US `GP6E01` Mario Party 6 disc image, extracted locally
  into `orig/GP6E01/`

`configure.py` pins the project tool versions and can download the configured
DTK, binutils, Metrowerks compiler archive, `sjiswrap`, and `wibo` when explicit
paths are not supplied. Generated tools and outputs remain under ignored
`build/`.

Optional path overrides are available through:

```sh
python configure.py --help
```

Important options include `--dtk`, `--binutils`, `--compilers`, `--sjiswrap`,
and, outside Windows, `--wrapper`.

## Diffing and investigation

[objdiff](https://github.com/encounter/objdiff) is strongly recommended for
relocation-aware object comparison and automatic rebuilds. The generated
`objdiff.json` is local build output and must not be committed.

`tools/decompctx.py` can still produce preprocessed decomp.me context. Agent
work should normally begin with the smaller evidence packet generated by
`tools/agent.py context`.

## Platform notes

### Windows

Native Python and Ninja are recommended. Add both to `%PATH%`. WSL and MSYS2
are not required; filesystem notifications used by objdiff may be less reliable
when the checkout crosses the Windows/WSL boundary.

### Linux

Install Python, Git, and Ninja through the distribution package manager. On
x86_64, the pinned `wibo` wrapper can be downloaded automatically. Other
architectures generally need Wine or an explicitly supplied wrapper.

### macOS

Install Python, Git, and Ninja. Metrowerks executables require a compatible Wine
runtime, such as Wine Crossover. If macOS quarantines the application after an
OS update, clear the quarantine only for the Wine installation you intentionally
installed.

## Private versus public checks

The following do **not** require retail files:

```sh
python -m unittest discover -s tools/tests -v
python tools/agent.py check --base <AI_BASE_COMMIT>
```

A source promotion additionally requires the locally extracted retail inputs,
configured compiler toolchain, serialized DOL/REL build, DTK checksum, and
explicit byte comparisons. Public CI intentionally does not contain or download
game assets.
