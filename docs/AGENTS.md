# Documentation and evidence instructions

These rules apply under `docs/`. Also follow the root `AGENTS.md`.

- Keep active workflow documentation short and current. Link to durable evidence
  rather than duplicating it.
- Treat `native_matching_wave*.md` and similar reports as historical laboratory
  records. Do not rewrite old results to fit a new conclusion; add a new report
  that cites and supersedes the relevant finding.
- Do not make agents load all historical reports. Put reusable facts, rejected
  probes, compiler behavior, names, and recovery debt in `config/recovery/`.
- State what was actually verified. Distinguish object proof, relocation proof,
  linked-container proof, and checksum proof.
- Use exact owners, symbols, stable identities, paths, and absolute dates.
- Avoid unsupported completion language. A binary-exact owner may still carry
  semantic, naming, data, or source-shape debt.
- Keep commands copyable and relative to the repository root.
- Update `docs/README.md` when adding an active workflow document. Historical
  evidence reports do not each need a navigation entry.
